## How It Works

1. **Select a file** — Drop a GIF, PNG sequence, APNG, or Live Photo video (MOV/MP4).
2. **Process locally** — Decoding and encoding run in your browser. Files are never uploaded to OmniGIF servers.
3. **Download** — Export a GIF, PNG, WebP, APNG, or a ZIP of frames — no watermark.
